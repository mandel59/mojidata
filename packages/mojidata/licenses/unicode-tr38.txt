The tracked build-data/unihan-tr38-properties.json is extracted property
metadata used internally to choose how Unihan values are split into tables.
It omits Description and is not included in the npm package's file allowlist.
The report itself is not distributed with the databases. The distributed
Unihan values come from Unihan.zip and carry the separately included
Unicode License v3 in unicode.txt.

Unicode's Terms of Use distinguish Technical Reports from Data Files; this
build-only report input is therefore recorded separately rather than assuming
that the data-files license grants rights to redistribute report text.
